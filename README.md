# Kata Lights Out

Classic "Lights Out" puzzle game

## The Goal
Turn off all the lights! Clicking on a light toggles it and its direct neighbors (top, bottom, left, and right).

## Project Files
- `index.php`: The controller that handles the game state and user clicks.
- `LightsOutGame.php`: The class containing the core game logic.
- `BoardView.php`: The HTML and Tailwind CSS UI.

## How to run it
Open your terminal in the project folder and start the PHP local server:

```bash
php -S localhost:8000
